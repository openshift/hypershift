# Spelling dictionaries

`dictionary.txt` and `dictionary_rare.txt` are unmodified codespell v2.4.1
(clear and rare dictionaries), preserving the existing verification vocabulary.

Source: <https://github.com/codespell-project/codespell/tree/v2.4.1/codespell_lib/data>

These dictionaries are derived from English Wikipedia and distributed under
Creative Commons Attribution-ShareAlike 3.0. See LICENSE. To update, replace both
files from the same codespell tag, retain attribution, and rerun spelling tests.
