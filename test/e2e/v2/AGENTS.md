# V2 E2E Test Framework

Follow [Writing V2 Tests](../../../docs/content/how-to/ci/v2-testing/writing-tests.md)
for authoritative authoring invariants and framework change procedures, including
for migrated tests. Existing code that violates those invariants is migration
debt, not an exception.

Backup/restore remains covered separately in [backuprestore/README.md](backuprestore/README.md).
